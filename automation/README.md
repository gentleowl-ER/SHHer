# 班表自動同步（Google Apps Script）

`schedule_sync.gs` 會在每天固定時間（預設清晨 5 點，台北時間），讀取「本月」和「下個月」的值班表 Google 試算表，再把讀到的班表寫進 SHHer 的雲端班表。班表頁的「班表連結」卡片也可以手動「立即同步」。

- **試算表維持私人。** 同步程式用你的 Google 帳號執行，只要這個帳號打得開試算表就好。
- **只讀兩個地方：**
  - 「Shiftcard」分頁：第 1 列是代碼、第 2 列是住院醫師姓名，A 欄是日期。
  - 「班表」分頁右側的「醫師姓名」表：只讀代碼和姓名兩欄。電話欄不會讀，Shiftcard 右側那張舊的代碼表也不會用。
- **主治醫師用姓名對應。** 先用該月份的代碼查出姓名，再用姓名去找系統裡的主治醫師。找不到這個人時，那一格會略過並寫進同步紀錄，不會改用系統代碼去猜。
- **只更新試算表上出現的日期。** 其他日期完全不動。

## 一次性設定

1. 用**打得開班表試算表的 Google 帳號**登入 <https://script.google.com>，按「新專案」，把專案命名為「SHHer 班表同步」。
2. 點左側「⚙ 專案設定」：
   - 時區選「(GMT+08:00) 台北」；
   - 勾選「在編輯器中顯示 "appsscript.json" 資訊清單檔案」。
3. 回到左側「編輯器」：
   - 點開 `appsscript.json`，把內容全部換成本資料夾的 `appsscript.json`；
   - 點開 `程式碼.gs`，把內容全部換成本資料夾的 `schedule_sync.gs`；
   - 按 💾 儲存。
4. 回到「⚙ 專案設定」，在最下方「指令碼屬性」按「新增指令碼屬性」，新增三筆：

   | 屬性 | 值 |
   |---|---|
   | `FB_PROJECT` | `shher-d2331` |
   | `FB_API_KEY` | 和網頁用的同一組 Firebase API Key。位置：repo 的 `index.html` 裡，搜尋 `FB_CONFIG`，複製 `apiKey:"…"` 引號內的文字 |
   | `SYNC_TOKEN` | 自己想一組通關碼，例如 20 個英文和數字混合。不要給別人，也不要寫進 repo |

5. 回到「編輯器」：
   1. 上方的函式選單選 `setup`，按「▶ 執行」。
   2. 跳出「需要授權」時，依序按：「審查權限」→ 選你的帳號 →「進階」→「前往 SHHer 班表同步（不安全）」→「允許」。
   3. 下方的執行紀錄出現「✅ 已建立觸發器」就完成了。這個觸發器每小時檢查一次，到了你設定的時間才會真的同步。
6. 右上角按「部署」→「新增部署作業」：
   1. 按齒輪圖示，類型選「網頁應用程式」。
   2. 「執行身分」選「我」。
   3. 「誰可以存取」選「所有人」。不知道通關碼的人呼叫也會被拒絕。
   4. 按「部署」，然後複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
7. 打開 SHHer，以管理員身分進入「人員與排班」→「班表」：
   1. 在「班表連結」卡片展開「⚙ 同步程式設定」，貼上第 6 步的網址和第 4 步的通關碼，按「🔌 測試連線」，應該會看到 ✅。
   2. 用 ‹ › 切到要設定的月份，貼上該月試算表的網址，按「💾 儲存並同步」。
   3. 畫面會顯示讀到的試算表標題、日期範圍和筆數，請確認月份正確。

通關碼只會存在你目前用的這台裝置。換一台裝置操作「立即同步」時，要再輸入一次。

## 每個月要做的事

到「班表」頁切到下個月，貼上該月試算表網址，可以提前貼。每月 25 號以後，如果下個月還沒有網址，頁面會提醒你；新的月份開始了卻還沒設定，會顯示紅字提醒。

## 同步紀錄

「班表連結」卡片裡的「同步紀錄」會列出每次同步的時間、月份、讀到的天數和筆數，以及略過的代碼和學員欄。常見的錯誤訊息：

- 「試算表無法開啟：沒有共用給執行同步的 Google 帳號，或網址錯誤」：把該月的試算表共用給第 1 步那個帳號（檢視者就夠了），或檢查網址有沒有貼錯。
- 「找不到「Shiftcard」分頁」或「找不到「班表」分頁」：分頁名稱被改了。改回原本的名稱即可。
- 「略過代碼：55=某某（系統內找不到…）」：這位醫師還沒建在 SHHer 的「主治醫師管理」，或兩邊的姓名寫法不同。建好或改成一致後，再按「立即同步」。

## 程式更新時

repo 的 `schedule_sync.gs` 有更新時：

1. 把新內容貼回 Apps Script 的 `程式碼.gs`，按 💾 儲存。
2. 按「部署」→「管理部署作業」→ ✏️ 編輯 →「版本」選「新版本」→「部署」。

網頁應用程式的網址不會改變，SHHer 這邊不用重新設定。
