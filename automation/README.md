# 班表自動同步（Google Apps Script）

`schedule_sync.gs` 會在每天固定時間（預設清晨 5 點，台北時間），讀取「本月」和「下個月」的值班表 Google 試算表，再把讀到的班表寫進 SHHer 的雲端班表。班表頁的「班表連結」卡片也可以手動「立即同步」。

- **不用每月貼連結。** 同步程式會在你的雲端硬碟依檔名找該月的班表，預設是「雙和{民國年}-{月}急診值班表」（例如 `雙和115-12急診值班表`）。只認完全相同的標題，「Copy of …」或「教學活動表」都不會被誤用；同標題有兩份時會停下來並記錄，不會猜。檔名規則改了的話，在指令碼屬性加 `SCHED_TITLE`（例如 `雙和{ROC}-{MM}急診值班表`）。
- **試算表維持私人。** 同步程式用你的 Google 帳號執行，只要這個帳號打得開試算表就好。
- **只讀兩個地方：**
  - 「Shiftcard」分頁：第 1 列是代碼、第 2 列是住院醫師姓名，A 欄是日期。
  - 「班表」分頁右側的「醫師姓名」表：只讀代碼和姓名兩欄。電話欄不會讀，Shiftcard 右側那張舊的代碼表也不會用。
- **主治醫師用姓名對應。** 先用該月份的代碼查出姓名，再用姓名去找系統裡的主治醫師。找不到這個人時，那一格會略過並寫進同步紀錄，不會改用系統代碼去猜。
- **只更新試算表上出現的日期。** 其他日期完全不動。
- **換班會自動更新。** 每天同步時，試算表上每一天都會整天重新寫入，所以 Shiftcard 上換了班，隔天清晨就會反映；急的話可以在班表頁按「立即同步」。
- **該月的醫師姓名表會存起來。** 網頁上「貼上班表」手動匯入時，主治醫師也會用這張表換成姓名對應，不用再另外貼姓名表。

## 一次性設定

1. 用**打得開班表試算表的 Google 帳號**登入 <https://script.google.com>，按「新專案」，把專案命名為「SHHer 班表同步」。
2. 點左側「⚙ 專案設定」：
   - 時區選「(GMT+08:00) 台北」；
   - 勾選「在編輯器中顯示 "appsscript.json" 資訊清單檔案」。
3. 回到左側「編輯器」：
   - 點開 `appsscript.json`，把內容全部換成本資料夾的 `appsscript.json`；
   - 點開 `程式碼.gs`，把內容全部換成本資料夾的 `schedule_sync.gs`；
   - 按 💾 儲存。
4. 指令碼屬性**不用填**：Firebase 設定會自動從公開的 SHHer 網頁讀取，通關碼由下一步的 `setup` 自動產生。（要自訂時才在「⚙ 專案設定 → 指令碼屬性」填 `FB_PROJECT`、`FB_API_KEY`、`SYNC_TOKEN`、`SCHED_TITLE`。）
5. 回到「編輯器」：
   1. 上方的函式選單選 `setup`，按「▶ 執行」。
   2. 跳出「需要授權」時（會要求「試算表」和「查看雲端硬碟檔案」權限。Google 的試算表程式庫連「讀取」也要求完整的試算表權限，程式只會讀、不會改任何試算表；雲端硬碟權限用來依檔名找每月班表），依序按：「審查權限」→ 選你的帳號 →「進階」→「前往 SHHer 班表同步（不安全）」→「允許」。
   3. 下方的執行紀錄出現「✅ 已建立觸發器」和「🔑 通關碼：…」就完成了。把通關碼抄下來，第 7 步要用；忘了可以再執行一次 `setup`，會顯示同一組。這個觸發器每小時檢查一次，到了你設定的時間才會真的同步。
6. 右上角按「部署」→「新增部署作業」：
   1. 按齒輪圖示，類型選「網頁應用程式」。
   2. 「執行身分」選「我」。
   3. 「誰可以存取」選「所有人」。不知道通關碼的人呼叫也會被拒絕。
   4. 按「部署」，然後複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
7. 打開 SHHer，以管理員身分進入「人員與排班」→「班表」：
   1. 在「班表連結」卡片展開「⚙ 同步程式設定」，貼上第 6 步的網址和第 5 步顯示的通關碼，按「🔌 測試連線」，應該會看到 ✅。
   2. 按「🔄 同步這個月」，畫面會顯示「依檔名自動找到」的試算表標題、日期範圍和筆數，請確認月份正確。

通關碼只會存在你目前用的這台裝置。換一台裝置操作「立即同步」時，要再輸入一次。

## 每個月要做的事

通常什麼都不用做：科部把新月份的班表共用給你之後，同步程式隔天清晨就會依檔名自動找到並同步（下個月的班表一出現就會先抓）。

只有兩種情況要手動貼網址：檔名和規則不同，或班表頁顯示找錯檔案。到「班表」頁切到該月，在「手動指定網址」貼上即可，手動網址優先。新的月份開始了卻還找不到班表時，頁面會顯示紅字，並寫出它在找的檔名。

## 同步紀錄

「班表連結」卡片裡的「同步紀錄」會列出每次同步的時間、月份、讀到的天數和筆數，以及略過的代碼和學員欄。常見的錯誤訊息：

- 「試算表無法開啟：沒有共用給執行同步的 Google 帳號，或網址錯誤」：把該月的試算表共用給第 1 步那個帳號（檢視者就夠了），或檢查網址有沒有貼錯。
- 「尚未設定班表來源網址，雲端硬碟也找不到「雙和…急診值班表」」：該月班表還沒共用給同步帳號，或檔名不同。確認共用，或在班表頁手動貼網址。
- 「無法搜尋雲端硬碟（需要重新授權…）」：舊版設定沒有雲端硬碟權限。依「程式更新時」更新 `appsscript.json` 和程式後，在編輯器執行一次 `setup` 重新授權。
- 「同步程式的授權不足…」：在 Apps Script 編輯器選 `setup` 按「執行」，再按一次「允許」。
- 「找不到「Shiftcard」分頁」或「找不到「班表」分頁」：分頁名稱被改了。改回原本的名稱即可。
- 「略過代碼：55=某某（系統內找不到…）」：這位醫師還沒建在 SHHer 的「主治醫師管理」，或兩邊的姓名寫法不同。建好或改成一致後，再按「立即同步」。

## 程式更新時

repo 的 `schedule_sync.gs` 有更新時：

1. 把新內容貼回 Apps Script 的 `程式碼.gs`（`appsscript.json` 有變時也一起貼），按 💾 儲存。
2. 權限有增加時（例如 v5.32 加了「查看雲端硬碟檔案」），在編輯器執行一次 `setup`，按「允許」。
3. 按「部署」→「管理部署作業」→ ✏️ 編輯 →「版本」選「新版本」→「部署」。

網頁應用程式的網址不會改變，SHHer 這邊不用重新設定。
